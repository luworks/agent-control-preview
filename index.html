自助体验完整控制台

取得包含 agent-control 的源码，在安装 Node.js 的本机终端，从仓库根目录运行：

node agent-control/tools/activity-demo.js

打开终端显示的本机地址，输入公开的 synthetic-demo-only，再尝试断线和清除令牌。请勿输入真实令牌。Ctrl-C 停止演示。它不调用 CLI、模型或供应商，不保存任务数据。

价值与现有限制

候选价值是减少在多个终端之间确认任务状态的切换成本；节省多少时间和付费意愿尚未由外部客户验证。正式产品目前是 Linux 单机单用户，不是团队共享或多机调度；不采集费用或 Token，不提供成本上限。清理不明会阻止新任务，但终态不保证所有后代退出或结果正确。正式 CLI 以用户权限执行，不是安全沙箱。

这是预览而非上线或收费承诺；真实用户、订阅和 MRR 尚无可核验数据。无外部字体、分析或网络请求。
